This directory contains all figures used in the IEEE TIFS submission manuscript.
Figures are generated by running the phase notebooks in order (Phase 1 → Phase 5).
Each figure filename maps directly to the corresponding paper section.

## How to Regenerate Figures

```bash
# Run notebooks in order:
jupyter nbconvert --to notebook --execute notebooks/Phase1_PBI_Enron_Mining.ipynb
jupyter nbconvert --to notebook --execute notebooks/Phase2_AIF_Profiler.ipynb
jupyter nbconvert --to notebook --execute notebooks/Phase3_FAL_FedAvg_DP.ipynb
jupyter nbconvert --to notebook --execute notebooks/phase4_collective_deception_evolution.ipynb
jupyter nbconvert --to notebook --execute notebooks/phase5_mirror_defense_evaluation.ipynb
```

All figures will be saved to `figures/` automatically.
